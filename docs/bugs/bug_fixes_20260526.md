# Daftar Bug dan Perbaikan (26 Mei 2026)

## 1. Bug sorting tanggal di Excel
Saya sudah setting mode sorting berdasarkan tanggal. Di aplikasi hasilnya sudah benar, karena data single sudah mengikuti date masing-masing. Tetapi di Excel masih mengikuti kategori single, bukan berdasarkan tanggal.

Jadi saat export ke Excel, sorting datanya tidak sama dengan yang tampil di aplikasi. Harusnya Excel mengikuti logic sorting yang sama seperti di aplikasi, yaitu berdasarkan date, bukan kategori.

Tolong dicek kenapa sorting di aplikasi dan di Excel bisa berbeda, karena ini harus disamakan.

## 2. Nama sheet saat download semua tahun
Saat download all year, nama sheet sekarang masih salah, misalnya:
* Revenue-Cost_0

Harusnya dibuat lebih jelas seperti:
* Sheet 1: Revenue-Cost_All
* Sheet 2: Laba Rugi_All

Tolong dibenerin naming sheet-nya.

## 3. Bug tahun di halaman Kasbon
Contohnya:
* Default tahun laporan = 2025
* Saya ubah halaman Kasbon ke tahun 2021

Lalu saya pindah ke Settlement, dan Settlement tetap di 2025 sementara Kasbon tetap di 2021. Ini sudah benar.

Tetapi saat saya klik menu Kasbon lagi untuk kedua kalinya, tahun di Kasbon malah kembali ke 2025. Harusnya jangan reset otomatis seperti itu.

Kasbon harus tetap di 2021 sampai:
* saya sendiri mengubahnya ke 2025, atau
* setting default tahun laporan diubah menjadi 2025 lagi, atau
* aplikasi di-restart / logout / masuk ulang.

Jadi state/filter tahun per halaman harus tetap tersimpan selama sesi aplikasi berjalan.

## 4. Tahun Settlement dan Kasbon jangan ikut berubah
Saat saya mengubah tahun di:
* Laporan Summary
* Laporan Tahunan

jangan sampai tahun di Settlement dan Kasbon ikut berubah.

Contohnya:
* Default = 2025
* Kasbon saya ubah ke 2021
* Lalu saya buka Laporan Tahunan dan ubah ke 2022

Saat balik ke Kasbon atau Settlement, tahunnya harus tetap 2021, bukan kembali ke 2025 atau ikut ke 2022.

Artinya:
* Settlement punya state tahun sendiri
* Kasbon punya state tahun sendiri
* Tidak boleh terpengaruh oleh halaman laporan

## 5. Laporan Tahunan dan Laporan Summary harus sinkron
Berbeda dengan Settlement dan Kasbon, untuk:
* Laporan Summary
* Laporan Tahunan

keduanya harus saling sinkron tahun filternya.

Contohnya:
* Laporan Summary diubah ke 2022
* Lalu buka Laporan Tahunan dan ubah ke 2024

Saat kembali ke Laporan Summary, tahunnya harus ikut menjadi 2024.

Jadi khusus kedua halaman laporan tersebut, filter tahun harus shared/sinkron.
