### Ringkasan Isi Teks

Teks tersebut merupakan transkrip diskusi yang membahas sistem pencatatan dan pengelolaan keuangan, dengan fokus utama pada alur *advance* (kasbon) dan *settlement*. Diskusi ini menjelaskan posisi *advance* di dalam kategori bank atau uang masuk (revenue), serta bagaimana sistem mencatat riwayat penarikan dan penyelesaian dana oleh karyawan. Melalui simulasi kasus menggunakan nama karyawan, teks merinci mekanisme persetujuan, pengurangan saldo saat *settlement*, hingga elemen-elemen spesifik yang harus dimasukkan ke dalam laporan akhir berformat Excel.

#### Topik 6: Logika Sistem / Aplikasi dalam Menghitung Saldo (*Balance*) dan *Settlement*

Total informasi yang ditemukan pada topik ini: 15 poin

"Berarti intinya di aplikasi ; Di itu advance nya itu ; Gak sama kayak settlement"

3. Jika *settlement* dilakukan tanpa ada riwayat *advance*, sisa *advance* dianggap 0 (nol).
"Kalau ada katanya 0"

"Balance tuh ; Ini apa ; Employernya ; Misalnya 8 juta"
5. Jika seseorang (contoh: Edwan) melakukan *settlement* 8 juta tapi tidak memiliki *advance*, saldo *advance* adalah nol.
"Di settlement nya sini nih ; Ini 8 ; Total 8 juta ; Edwan gak ada ; Nol"
6. Dalam kasus Edwan, perusahaan (bapak) harus mengeluarkan uang bayaran sebesar 8 juta (Balance to employee).
"Balan tuh employee nya ; 8 juta ; Pak pengeluarin duit ; 8 juta ; Bayar ; Gitu loh"
7. Jika terdapat *advance* (misalnya 10 juta) dan *settlement* (8 juta), maka akan bersisa uang 2 juta.
"Tapi kalo ada advance nya ; Berapa advance nya ; Kalo advance nya 10 juta ; Ada sisa 2 juta"
8. Jika sisa *advance* lebih besar (uang lebih), tidak ada istilah "Balance to employment" (uang yang harus dibayar ke karyawan).
"Tidak ada balance to employment"
9. Tidak perlu ada istilah "Balance to company".
"Balance to company ; Nggak usah"
10. Uang sisa tersebut langsung dikembalikan (masuk lagi) ke dalam kategori bank di sistem.
"Karena ; Langsung masuk lagi ke dalam ; Sini bank sini ; Itu yang dimaksud ; Omalan tuh ; Masuk lagi sini ; Disitulah"
11. Sistem akan mencatat riwayat berupa: nilai *Advance*, jumlah *Settlement*, sisa *Advance*, dan *Balance*.
"Ada history nya tuh ; Advance ; The settlement ; Sisa ; Ini sisa advance nya ; Ada balance ; Berapa"
12. Jika sisa *advance* habis terpakai, maka angkanya menjadi nol.
"Kalo misalnya ; Abis ; Sisa advance ; Nol"
13. Jika sisa *advance* nol, pembuatan *settlement* berikutnya tidak akan memunculkan pertanyaan tentang *advance* sebelumnya.
"Jadi nanti kalo misalnya ; Dia bikin settlement lagi ; Nggak ada advance nya ; Waktu ditanya ; Waktu di klik ; Ini misalnya total ini ; Di klik sini ; Nggak ada lagi pertanyaan"
14. Sistem langsung menetapkan nilai nol jika tidak ada lagi riwayat *advance* untuk orang tersebut (contoh: Titis).
"Tanyanya ; Ada advance ke titis ; Nggak ada ; Langsung di buat nol"
15. Lawan bicara mengonfirmasi bahwa ia mengerti/nyambung dengan penjelasan sistem tersebut tanpa ingin berdebat.
"Nyambung gak ; Ya ; Oke ; Oke ; Ya gak apa-apa ; Namanya ; Itu maksudnya ; Ini itu ; Cuman gak bisa berdebat aja dia"
