# Prompt 5 — Developer Task List

Berdasarkan PRD final yang sudah dibuat, tambahkan **Developer Task List** ke bagian paling bawah file.

Jangan mengubah atau menghapus PRD final yang sudah ada.

Gunakan format:

## Developer Tasks

### UI

- [ ] ...

### Interaction

- [ ] ...

### Validation

- [ ] ...

### Error & Edge Cases

- [ ] ...

### Navigation

- [ ] ...

### Testing

- [ ] ...

## Aturan Developer Tasks

- Setiap task harus berasal dari requirement yang sudah ada di PRD.
- Jangan membuat fitur baru.
- Jangan menambahkan asumsi teknis yang tidak diperlukan.
- Task harus konkret dan dapat dikerjakan developer.
- Pecah requirement yang besar menjadi task yang masuk akal.
- Pastikan seluruh requirement penting di PRD memiliki task yang sesuai.
- Tambahkan task testing untuk behavior penting, validasi, error state, edge case, dan navigation.
- Jangan menghapus atau mengubah isi PRD final.
- Hanya tambahkan section `## Developer Tasks` di bagian paling bawah file.

**Wajib:** update file:

`D:\Aplikasi\EWIApps\docs\mdcatatan\[NAMA_HALAMAN].md`

Task yang berkaitan dengan interaksi pengguna.

### Validation

### Error & Edge Cases

Task yang berkaitan dengan error, loading, empty state, disabled state, dan kondisi khusus.

Task yang berkaitan dengan perpindahan halaman atau perubahan flow.

Task untuk memastikan seluruh behavior dan requirement pada PRD berjalan sesuai dokumentasi.
