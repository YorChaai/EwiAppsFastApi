# Prompt 1 — Ekstraksi Seluruh Fitur & UI

sekarang fokus ke setting
Pelajari source code halaman yang ingin di fokuskan dan lihat secara menyeluruh.

Tujuan tahap ini adalah membuat **inventaris lengkap seluruh hal yang dapat dilihat, digunakan, atau dialami pengguna pada halaman tersebut**.

Identifikasi sebanyak mungkin aspek yang benar-benar terdapat di source code, termasuk tetapi tidak terbatas pada:

- Halaman dan section
- Header dan title
- Text/information
- Input/form
- Button
- Icon
- Link
- Dropdown
- Checkbox/toggle
- Search
- Filter
- Tab
- Card
- Table/list
- Modal/dialog
- Popup
- Snackbar/toast
- Upload/download
- Navigation
- Loading state
- Empty state
- Disabled state
- Success state
- Error state
- Confirmation
- Show/hide content
- Responsiveness/layout
- Perubahan tampilan berdasarkan kondisi tertentu
- Role/permission yang memengaruhi tampilan
- User action
- Hasil setelah user melakukan action
- Data yang ditampilkan kepada user
- Fitur khusus atau tersembunyi yang ditemukan dari source code

Untuk tahap ini, **jangan membuat PRD dan jangan membuat narasi**.

Buat hasil dalam bentuk bullet points agar seluruh fitur mudah diperiksa satu per satu.

## Aturan Utama

1. **Source code adalah sumber kebenaran utama.**
2. Jangan mengarang fitur.
3. Jangan menambahkan fitur hanya karena fitur tersebut umum terdapat pada halaman sejenis.
4. Jangan mengasumsikan fitur ada jika tidak ditemukan.
5. Jangan menghilangkan fitur hanya karena terlihat kecil atau sederhana.
6. Jika terdapat fitur yang hanya muncul pada kondisi tertentu, tetap dokumentasikan.
7. Jika terdapat perbedaan behavior berdasarkan role, status, device, atau kondisi tertentu, dokumentasikan.
8. Jangan terlalu fokus pada nama function, class, variable, API, database, atau detail implementasi teknis. Fokus utama adalah **apa yang dapat dilihat dan dialami pengguna**.
9. Jangan melakukan penyederhanaan pada tahap ini. Lebih baik terlalu lengkap daripada ada fitur yang terlewat.
