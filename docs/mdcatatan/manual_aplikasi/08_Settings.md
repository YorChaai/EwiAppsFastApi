# Product Requirements Document (PRD)

## Modul: Pengaturan Sistem (Settings)

Halaman Pengaturan Sistem berfungsi sebagai pusat kendali personalisasi akun pengguna dan konfigurasi global aplikasi. Saat pengguna pertama kali membuka halaman ini, aplikasi akan memuat data preferensi dan saldo secara mandiri, ditandai dengan indikator siklus pemuatan di tengah layar. Tampilan utama didominasi oleh Kartu Profil di bagian atas yang menampilkan foto avatar (atau inisial nama yang dikapitalisasi jika tidak ada foto), nama lengkap, _username_, serta porsi detail seperti peran, No HP, dan Tempat Kerja. Di dalam kartu profil ini juga terintegrasi elemen antarmuka yang menunjukkan ringkasan uang kasbon (Bank Advance), beserta tombol khusus untuk melompat ke layar Logbook riwayat transaksi. Halaman ini bersifat dinamis; bagi pengguna dengan peran manajerial, sebuah tombol aksi khusus bertuliskan "Manager Panel" akan muncul di sudut tajuk (_AppBar_). Bila ditekan, tombol ini akan membuka kunci (menampilkan) kumpulan menu pengaturan tingkat administrator di bagian bawah layar yang secara bawaan selalu disembunyikan.

Pengguna dapat memodifikasi data diri mereka dengan menekan tombol ikon bergambar pensil pada profil, yang akan memunculkan sebuah dialog formulir pengubahan identitas (nama, no HP, tempat kerja, serta input kata sandi). Di dalam dialog ini, pengguna juga difasilitasi untuk mengganti foto profil menggunakan fitur pemotongan gambar otomatis berbasis sistem operasi. Selain itu, pada Kartu Profil terdapat sebuah tombol interaktif penanda status tautan akun Google. Jika akun belum terhubung, tombol bergaris tepi ("Hubungkan Google") akan memicu antarmuka integrasi pihak ketiga. Terdapat logika penyelesaian masalah (Bypass) tersembunyi pada tahap ini; jika koneksi Google gagal akibat gangguan jaringan, aplikasi akan memunculkan dialog peringatan khusus yang menawarkan pengguna untuk mensimulasikan keberhasilan koneksi secara paksa demi keperluan pengujian internal. Sebaliknya, jika akun sudah tertaut, tombol akan berganti warna menjadi hijau tebal ("Google Terhubung"), yang apabila ditekan akan memunculkan dialog konfirmasi standar untuk memutus tautan secara permanen.

Di area preferensi, pengguna dapat menyesuaikan Tema Aplikasi secara instan tanpa perlu memuat ulang halaman. Fitur ini menggunakan tombol pilihan ganda horizontal dengan opsi perpindahan mode terang, gelap, atau mengikuti kalibrasi sistem perangkat. Tepat setelahnya, terdapat pengaturan "Default Tahun Laporan" berupa menu tarik-turun (Dropdown) yang sifatnya sangat krusial karena parameter tahun yang dipilih di sini akan mengubah orientasi tampilan seluruh data aplikasi. Ketika tombol "Simpan Default Tahun" dieksekusi, sistem tidak hanya sekadar menyimpan angka, namun di latar belakang sistem secara otomatis akan melepaskan perintah _Sync All From Settings_. Perintah ini memaksa seluruh modul turunan dalam aplikasi untuk menyegarkan dan mengonstruksi ulang datanya agar selaras dengan rentang tahun yang baru dikonfigurasi.

Bagi Manager yang telah mengaktifkan sakelar Manager Panel, mereka akan dihadapkan pada kumpulan kontrol tingkat tinggi yang secara visual dibedakan menggunakan label stempel khusus "MANAGER ONLY". Fasilitas pertama adalah menu pengelolaan pengguna dengan tombol "Lihat Account List" yang akan memanggil dialog daftar akun. Selanjutnya, terdapat tombol "Kelola Deadline Notifikasi" yang akan melontarkan pengguna ke layar khusus pengaturan tenggat waktu penyelesaian laporan. Manager juga memiliki wewenang merubah lokasi fisik data melalui kolom input teks direktori penyimpanan, lengkap dengan tombol simpan. Tersedia pula menu "Pembersihan Data Selektif" yang menampung tombol berwarna bahaya untuk menavigasi ke halaman alat pemusnah data permanen.

Fitur manajerial dengan risiko tertinggi terletak pada blok "Manajemen Database" yang menawarkan fungsi pencadangan (Backup/Restore) lewat dua tombol berdampingan: Export dan Import. Menjalankan fungsi Export akan membuat salinan cadangan _database_ dan memunculkan dialog sukses yang merincikan alamat direktori tempat file disimpan. Jika Manager memilih fungsi Import, layar pemilih file akan terbuka dengan lapis keamanan validasi ketat; sistem menolak keras file yang tidak berakhiran `.db` atau `.sql`. Jika file valid, sistem menampilkan dialog pratinjau berupa ringkasan jumlah tabel dan baris dari file cadangan, disertai kotak peringatan merah tebal bahwa database saat ini akan dihapus. Begitu import disetujui, sistem menjalankan sinkronisasi paralel masif: sistem memuat konfigurasi tahun dari database baru, memuat ulang seluruh fungsi _state provider_ secara bersamaan, dan akhirnya merekayasa tumpukan navigasi (_Remove Until_) untuk me-restart antarmuka aplikasi dari titik nol, sehingga antarmuka bersih sepenuhnya dari memori database lama. Setiap langkah keberhasilan maupun kegagalan pada operasi berisiko tinggi ini selalu diawasi dan dilaporkan seketika kepada pengguna melalui notifikasi Snackbar.
